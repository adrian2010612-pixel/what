# WHAT IF — Green & Orange Website

## Overview

WHAT IF is an educational and interactive platform for exploring alternative sports, historical, technological, future, and social scenarios.

The website lets visitors:

- Discover What If scenarios
- Filter scenarios by category
- Search scenarios
- Open full readable scenario articles
- Explore alternative timelines
- Make predictions
- Take quick quizzes
- Save/share scenarios in the intended product flow
- Discover ideas through IdeaHub
- Pitch new ideas

## Design Direction

The current visual identity uses:

- Deep green as the primary background
- Light orange as the main accent
- White/off-white text
- Dark green cards and overlays
- Rounded modern UI
- Editorial/magazine-inspired layouts
- Cinematic category imagery

Blue and purple are intentionally not used as the main accent colors.

## Category Imagery

The website uses different imagery depending on the scenario:

- **Sports:** stadium and football/basketball imagery
- **History:** historical/event imagery such as the Titanic
- **Technology:** futuristic AI and technology imagery
- **Future:** Mars and futuristic environments
- **Automotive:** modern car imagery
- **Virtual Reality:** VR-focused imagery

## How to Run

No server is required for the basic prototype.

1. Extract the ZIP.
2. Open the `what-if-site-assets` folder.
3. Double-click `index.html`.
4. The website should open in your browser.

For development, you can also run it through a local server such as VS Code Live Server.

## Important Prototype Notes

This is a front-end prototype.

Features that normally require a backend include:

- Real user accounts
- Secure authentication
- Database storage
- User-created scenario publishing
- Real comments
- Real likes/follows/saves
- Idea ownership
- Investment functionality
- Payments
- Notifications
- Moderation
- Admin controls
- Analytics

Any investment functionality should remain clearly marked as a demo until the production version has the required legal, payment, identity-verification, securities, fraud-prevention, privacy, and jurisdiction-specific compliance infrastructure.

## Scenario Content Rules

The platform should clearly distinguish between:

- **FACT** — supported by the real historical/sporting/technological record
- **PLAUSIBLE** — a reasonable alternative based on known circumstances
- **POSSIBLE** — an alternative that could have happened but is less certain
- **SPECULATIVE** — highly uncertain or imaginative

Hypothetical outcomes should never be presented as real historical facts.

## Accessibility

The website should maintain:

- Semantic HTML
- Clear labels
- Keyboard navigation
- Visible focus states
- Readable contrast
- Responsive layouts
- Appropriate alternative text for meaningful images
- Reduced-motion support where possible
